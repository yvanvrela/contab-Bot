# Sprint 12: Dockerización del Proyecto (Brief General)

## Objetivo Principal
Contenerizar la aplicación `contabBot` utilizando Docker y Docker Compose para garantizar que el proyecto pueda ser ejecutado en cualquier servidor (Linux, Windows, Mac) sin necesidad de configurar manualmente entornos virtuales, variables de sistema, ni lidiar con instalaciones locales de navegadores o drivers gráficos.

## Fases del Proyecto

1. **Sprint 12.1**: Adaptación del Código Fuente (Soporte Remoto para Selenium).
2. **Sprint 12.2**: Construcción de la Imagen (`Dockerfile` y `.dockerignore`).
3. **Sprint 12.3**: Orquestación (`docker-compose.yml`), incluyendo el contenedor aislado de Firefox y el mapeo de volúmenes persistentes para SQLite y discos de red (`Z:/`).
4. **Sprint 12.4**: Integración de la API (Opcional).
